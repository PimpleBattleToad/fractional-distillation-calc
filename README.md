# Калькулятор дробной перегонки

Офлайн-калькулятор для второй перегонки спирта-сырца: считает головы, тело и хвосты по
абсолютному спирту, объём заряда после разбавления, выход напитка и поправку показаний
ареометра на температуру.

Одностраничное приложение на чистом HTML/CSS/JS: без сборки, зависимостей и интернета.
Работает и на компьютере, и на телефоне, устанавливается как приложение (PWA) и
открывается по Wi-Fi прямо с домашнего компьютера.

**Открыть в интернете:** <https://pimplebattletoad.github.io/fractional-distillation-calc/>
(этот же адрес открывайте на телефоне — по https приложение ставится на главный экран
и работает офлайн).

## Как открыть на компьютере

Двойной клик по `index.html` — работает прямо с диска (`file://`).

Либо через локальный сервер, если удобнее:

```powershell
node serve-lan.js      # http://localhost:8080
# или: python -m http.server 8000
```

Вкладку можно открыть сразу: `index.html#dilute` или `index.html?tab=guide`
(вкладки: `distill`, `dilute`, `guide`).

## Как открыть на телефоне

Телефону нужен адрес, поэтому файл раздаётся по домашней сети.

1. Компьютер и телефон — в одной Wi-Fi сети.
2. Запустите `serve-lan.cmd` (или `pwsh -File .\serve-lan.ps1`, порт можно задать:
   `serve-lan.cmd 8081`).
3. В окне появятся адреса вида `http://192.168.1.42:8080/index.html` — откройте такой
   адрес в браузере телефона.
4. Если страница не открывается, разрешите Node.js доступ к частной сети в запросе
   брандмауэра Windows (при первом запуске).

Что сделано для телефона:

- одна колонка, крупные поля ввода (16 px — iOS не увеличивает страницу при фокусе);
- ползунки с большими бегунками, кнопки не меньше 44–48 px;
- внизу липкая строка с главным числом вкладки («2,40 л АС» на перегонке,
  «3,13 л воды» на разбавлении) и кнопкой «Скопировать»;
- запрет случайного зума и `touch-action: manipulation` — без двойных тапов;
- учтён вырез внизу экрана (`env(safe-area-inset-bottom)`).

Внутри Telegram (Mini App) приложение дополнительно разворачивается на весь экран.

### Диагностика вёрстки

Если что-то «вылезает» за край экрана, откройте адрес с `?debug`, например
`http://192.168.1.42:8080/index.html?debug`. Внизу появится строка с шириной экрана,
масштабом и списком элементов, которые выходят за пределы страницы.

## Установка как приложение

На телефоне откройте адрес по Wi-Fi (или с хостинга) и добавьте страницу на главный экран:

- **Android / Chrome**: меню → «Установить приложение» / «Добавить на главный экран»;
- **iPhone / Safari**: «Поделиться» → «На экран "Домой"».

Дальше приложение запускается без адресной строки, а после первого открытия работает
офлайн: `sw.js` кэширует страницу, стили, скрипты и иконки.

> Офлайн-режим и установка работают только по `http://localhost` или `https://` —
> браузеры не дают сервис-воркеру работать с `file://`. Открытие двойным кликом по
> `index.html` полностью работоспособно, просто без установки и офлайн-кэша.

## Что внутри

**Перегонка** — основной расчёт.

- спирт-сырец: объём и крепость (можно считать без разбавления);
- разбавление перед перегонкой до заданной крепости (обычно 20 % об.);
- сырьё: сахарная, зерновая, фруктовая, виноградная брага — от него зависит норма голов;
- головы в % от АС, крепость останова отбора тела, средняя крепость тела;
- результат: абсолютный спирт, объём голов (мл), объём тела, спирт в хвостах, выход напитка 40 %;
- полоса фракций, пошаговый план перегонки и кнопка «Скопировать расчёт»;
- блок «Сырец из браги»: пересчёт браги (по объёму и крепости или по сахару и гидромодулю)
  в объём сырца и подстановка результата в расчёт.

**Разбавление** — сколько воды добавить к спирту, чтобы получить нужную крепость,
плюс поправка показаний ареометра к 20 °C.

**Методика** — порядок работы, формулы, ориентиры по сырью, температуры кипения примесей,
частые ошибки и безопасность.

Состояние сохраняется в `localStorage` (ключ `fractional-distillation-calc/v1`),
кнопка «Сбросить данные» возвращает значения по умолчанию.

## Расчётная модель

Все величины — по абсолютному спирту (АС): `АС = объём × крепость / 100`.

| Величина | Значение по умолчанию | Комментарий |
| --- | --- | --- |
| Крепость голов | 88 % об. | средняя по фракции, первый отбор крепче |
| Крепость хвостов | 20 % об. | средняя по фракции |
| Крепость сырца при пересчёте из браги | 30 % об. | обычная первая перегонка |
| Средняя крепость тела | 62 % об. | пересчёт спирта тела в объём |

Разбавление:

```
вода = объём × (крепость / целевая − 1)
```

Доли фракций:

```
головы = headsPct / 100
хвосты = clamp(0.005 × stopAbv − 0.05, 0.05, 0.30)
тело   = 1 − головы − хвосты
```

То есть чем выше крепость, на которой остановлен отбор тела, тем больше спирта уходит
в хвосты: 40 % → 15 %, 50 % → 20 %, 60 % → 25 %, 70 % → 30 %.

Объёмы:

```
Vголов = АС × доля_голов / 0.88
Vтела  = АС × доля_тела / (крепость_тела / 100)
АСхвостов = АС × доля_хвостов,  Vхвостов = АСхвостов / 0.20
напиток 40 % = АС_тела / 0.4
```

Брага и сахар:

```
АС = объём_браги × крепость / 100
Vсырца = АС / 0.30

вода = сахар × гидромодуль
объём_браги = вода + сахар × 0.6      (0.6 л — объём, который занимает 1 кг сахара)
АС = сахар × выход_сырья              (сахарная 0.60, зерновая 0.55, фруктовая 0.50, виноградная 0.58 л/кг)
```

Поправка ареометра (оценочная линейная модель):

```
крепость_20 = показание − k × (t − 20)
k = clamp(0.4 − 0.0012 × показание, 0.15, 0.45)   %/°C
```

Это приближение: у каждого ареометра своя таблица поправок из паспорта. Для точных
измерений пользуйтесь таблицей прибора, а расчёт — для быстрой оценки.

## Тесты

Расчётное ядро (`calc.js`) не зависит от DOM, поэтому проверяется в Node без браузера.
Всего 55 проверок в четырёх файлах.

```powershell
node tests/calc.test.js       # математика: 21 проверка
node tests/ui-ids.test.js     # связка разметки и скрипта: 12 проверок
node tests/app-smoke.test.js  # прогон app.js в поддельном DOM: 13 проверок
node tests/test-pwa.js        # manifest, сервис-воркер, иконки, сервер: 9 проверок
```

Или сразу все:

```powershell
npm test
```

`ui-ids.test.js` сверяет `index.html` с `app.js` и `pwa.js`: все `id`, `data-key`,
`data-raw`, `data-tab` и `data-washmode` должны существовать и быть согласованы со
справочником сырья в `calc.js`.

`app-smoke.test.js` исполняет `app.js` в минимальной DOM-заглушке (`node:vm`) и проверяет
реальные строки интерфейса: `2,40` л АС, `218` мл голов, `2,98` л тела, `4,62` л напитка,
липкую строку на каждой вкладке, план перегонки, реакцию на ввод и сохранение в `localStorage`.

`test-pwa.js` проверяет manifest (имя, цвета, иконки нужных размеров — размеры читаются
из заголовка PNG), список кэша сервис-воркера (все файлы существуют), сервер для телефона
и сборку архива.

> `node --test tests/` в этом окружении падает с `spawn EPERM` (runner поднимает дочерний
> процесс), поэтому тесты запускаются по файлам — так, как указано выше.

## Структура

```

icons/          иконки 180/192/512 и maskable-512

```

## Ограничения

- Расчёт ориентировочный: реальный выход зависит от браги, оборудования и скорости отбора.
- Крепость проверяйте ареометром при 20 °C — приложение лишь оценивает поправку.
- Продукт предназначен только для личного употребления, 18+. Не управляйте техникой
  и не работайте с открытым огнём рядом с аппаратом.
